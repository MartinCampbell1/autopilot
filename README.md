# Autopilot

Autopilot is a standalone CLI for orchestrating autonomous AI programmers with account rotation, critic loops, and project-level automation.

## Development

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
autopilot version
```

## Current Status

Phase 1 scaffolds the Python package, CLI entrypoints, and core components that later phases build on.
