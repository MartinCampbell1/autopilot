# Code Of Conduct

## Our Standard

This project expects direct, respectful, and technically grounded collaboration.

Examples of expected behavior:

- discuss ideas, code, and tradeoffs on their merits
- assume good intent while staying concrete about problems
- give actionable review feedback
- keep disagreements professional and evidence-based
- help newcomers understand project constraints and verification expectations

Examples of unacceptable behavior:

- harassment, threats, or personal attacks
- discriminatory or demeaning language
- deliberate disruption, bad-faith trolling, or repeated escalation without technical substance
- publishing other people's private information without permission

## Maintainer Responsibilities

Maintainers may edit, remove, or reject comments, issues, pull requests, and other contributions that violate this code of conduct or make collaboration materially harder.

## Scope

This code of conduct applies in repository discussions, pull requests, issues, releases, and other project-managed collaboration spaces.

## Reporting

If you experience or observe unacceptable behavior, contact the project maintainer through GitHub using a private channel when possible. Reports will be reviewed promptly and handled with discretion.
